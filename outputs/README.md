# Outputs

This directory is intentionally kept empty in git except for `.gitkeep` and this README.

Paper runs write artifacts to:

```text
outputs/runs_human_gold_v2/{run_id}/
outputs/runs_human_gold_v2/ablation_{setting}/
outputs/benchmark_runs/{run_id}/
```

Do not commit generated run artifacts, cache files, JSONL predictions, metrics, CSV tables, or temporary outputs.
