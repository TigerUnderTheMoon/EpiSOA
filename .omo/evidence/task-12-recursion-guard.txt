Wave 2 Task 12: Recursion Depth Guard for _fallback_to_legacy_single_pass
======================================================================
Date: 2026-06-17
Repository: D:\Workplace\EpiSOA

Goal: Add recursion depth guard (max_depth=2) to prevent infinite recursion
in _fallback_to_legacy_single_pass.

Changes Made:
-------------

1. src/episoa/attribution/schema_attributor.py

   a. Added `import logging` and `logger = logging.getLogger(__name__)`
      at module level for error logging.

   b. attribute_event() - Added `_fallback_depth: int = 0` parameter
      (internal, default 0). Propagated to attribute_event_two_pass().

   c. attribute_event_two_pass() - Added `_fallback_depth: int = 0`
      parameter. Passed as `depth=_fallback_depth` to all 3 call sites
      of _fallback_to_legacy_single_pass (stage_parse_failure,
      empty_stage_candidates, canonical_merge_failure).

   d. _fallback_to_legacy_single_pass() - Added `depth: int = 0`
      parameter. Guard: if depth > 2, logs error and returns [], {}.
      Recursive call to attribute_event() passes `_fallback_depth=depth + 1`.

2. tests/test_schema_attributor.py

   Added test_fallback_recursion_guard() that calls
   _fallback_to_legacy_single_pass with depth=3 and asserts the return
   is ([], {}).
