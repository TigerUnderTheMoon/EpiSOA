## 选择方法

本次采用`criterion-based purposive sampling + maximum variation sampling`。必要条件为：2023年以后发生；时间、地点与触发明确；预计可形成至少3个来源谱系；包含官方/原始材料和独立报道或公开互动；能够覆盖来源级Effect、Claim、Evidence与跨文档Fusion。

六事件不是总体抽样，不用于领域代表性结论。选择目标是让v1.5尽可能早暴露Schema、Evidence gate、Attribution、Blocking、APCF和Dossier边界问题。

- 公共安全：黑龙江省政府救援信息、公开事故调查材料、黑龙江省住建厅行政处罚。
- 城市交通：北京市交通委应急处置信息、北京市应急管理局事故调查报告。
- 数字治理：中国网信网征求意见公告、新华社说明、中国网信网最终答记者问及正式办法。

## Document冻结前审计

每个事件建立6–8篇Document清单后逐项确认：全文可访问、来源角色、`reporting_source_id`、`primary_source_id`、`derivation_type`、发布时间、正文边界、内容hash和是否存在转载关系。

若某事件不能满足至少3个来源谱系或关键主体材料不可访问，只能在首次模型推理前替换，并在`docs/m5_change_log.md`登记。不得查看M3或Fusion结果后替换。
