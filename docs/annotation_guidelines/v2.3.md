# EpiSOA Annotation Guideline v2.3

This guideline defines the paper-grade path from `silver_v1` to `human_gold_v2`.
LLM output is reviewer input only. It is never a quality judge and never final gold.

## Inclusion Rules

- Include only concrete public-event stakeholder opinion attribution records.
- A tuple must contain one stakeholder, one atomic opinion/action stance, one sentiment label, one rationale, and evidence IDs from the same event.
- A chain must describe evidence-grounded event evolution, not generic background.
- Each final tuple or chain should have at least two independent source signatures. Single-source rows are `low_confidence` and require explicit human review notes.

## Exclusion Rules

- Exclude rows inferred only from media framing, vague public mood, or event background.
- Exclude non-public or login-only social content.
- Exclude duplicate stakeholder-opinion rows unless they represent materially different evidence-grounded claims.
- Exclude rows without valid evidence IDs or with evidence from another event.

## Source Type Taxonomy

- `news`: publicly accessible news reporting.
- `official`: government, court, institutional, or enterprise official publication.
- `forum`: public forum and discussion pages.
- `public_social`: public social-media snippets, indexed posts, or social content quoted by public pages.
- `public_interaction`: public comments or interaction traces that are accessible without login and legally collectable.
- `public_web`: other publicly accessible web pages.

## Edge Cases

- Official response without explicit sentiment is usually `neutral`.
- Public concern, complaints, opposition, safety risk, or accountability demand is `negative`.
- Broad labels such as "public" are allowed only when evidence cannot support a more specific group.
- A rationale may summarize support, but must not add motives or causal claims absent from evidence.
- Chain nodes may compress chronology, but every node must be traceable to evidence.

## Human Review Protocol

- Three annotators independently review the same rows after passing a 20-item qualification test with accuracy above 85%.
- Independent rows keep `adjudication_status=independent_review`.
- IAA is computed before adjudication. Target Fleiss' Kappa is `>0.80`; `0.70` is the minimum for paper-grade release.
- Conflict rows are routed to an expert adjudicator. Only rows with `adjudication_status=adjudicated_final` may enter `human_gold_v2`.

## Reporting Requirements

- Report annotator qualifications, IAA values, conflict count, adjudication policy, and error type distribution in the paper method or appendix.
- State explicitly: "All benchmark data were strictly held out during model development and LLM pre-annotation."
- Release the guideline version, independent annotation sheets, adjudication sheet, audit log, and benchmark manifest.
